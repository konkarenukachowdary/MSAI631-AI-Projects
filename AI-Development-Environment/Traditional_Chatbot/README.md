# Smart Rule-Based Personal Assistant

## Overview
This project implements a **traditional rule-based chatbot** using Python. Unlike LLM-based chatbots, SmartBot uses predefined rules, keyword matching, and conditional logic to understand user queries and generate responses.

The chatbot was developed in **Google Colab** and includes a **Gradio** interface for interactive conversations.

## Features
- Greeting users
- Displaying chatbot capabilities
- Current date and time
- AI, Machine Learning, Deep Learning, and Python information
- Random jokes
- Motivational quotes
- Coin toss and dice roll
- Graceful handling of unknown inputs
- Interactive web interface using Gradio

## Technologies Used
- Python 3
- Google Colab
- Gradio

## Project Structure

Simple_Traditional_Chatbot.ipynb
README.md
requirements.txt

## How to Run

1. Open `Simple_Traditional_Chatbot.ipynb` in Google Colab.
2. Install the required packages:
   pip install -r requirements.txt
3. Run all notebook cells.
4. Launch the Gradio interface and interact with SmartBot.
